# Treasure Hunt Platform

## Quick Start Guide

This project is a full-stack application with a React frontend and Node.js backend. It's ready to run out of the box! (MongoDB is connected to a cloud cluster, so no local database setup is required).

### To Run on Windows:
Simply double-click the `start.bat` file. 
It will automatically:
1. Install all backend dependencies.
2. Install all frontend dependencies.
3. Open two terminal windows running the server and client.
4. Your browser will automatically open the app at `http://localhost:5173`.

### To Run on Mac/Linux:
Open your terminal in this directory and run:
```bash
chmod +x start.sh
./start.sh
```

### Alternatively (Using npm directly):
If you have Node.js installed, you can simply run:
```bash
npm install
npm start
```

## Admin Panel
To view the admin dashboard, go to: `http://localhost:5173/admin` (or wherever your frontend is running, then add `/admin`).
